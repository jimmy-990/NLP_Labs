# Lab 8 – Part-of-Speech (POS) Tagging

POS tagging using NLTK and spaCy.

- **Task 1:** Printed the coarse tag, fine-grained tag, and explanation for "play", then for every word in the sentence.
- **Task 2:** Compared "google" and "table" across sentences. spaCy tags each by context: Google (proper noun) vs google (verb), table (noun) vs table (verb).
- **Task 3:** Visualized the POS tags and dependencies with displaCy.

**Requirements:** `nltk`, `spacy`, `en_core_web_sm`, NLTK data `punkt_tab` and `averaged_perceptron_tagger_eng`
