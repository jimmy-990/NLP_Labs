# Lab 11 Attention with RNN

A simple RNN with attention that reads a question and picks the right answer group from a small QnA dataset of 168 questions and 12 answer groups

## Steps

1. Load and clean the questions
2. Turn words into numbers and add padding
3. Build an RNN with an attention layer
4. Train for 50 epochs
5. Plot attention weights for each word

## Tasks

- Task 1 shows attention for three questions and finds the top word in each
- Task 2 compares attention for two questions with the same meaning

## Run

Upload Lab_11_QnA_Dataset.csv to Colab then run the cells in order
