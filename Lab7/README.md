# Lab 7 — Large Language Models (LLMs)

This lab explores the three main Transformer model families using Hugging Face `transformers`.

## Models Used
| Family | Model | Task |
|---|---|---|
| Decoder-only | DistilGPT-2 | Text generation |
| Encoder–decoder | FLAN-T5-small | Translation & summarization |
| Encoder-only | DistilBERT (SST-2) | Sentiment classification |

## Tasks
- **Task 1:** Matched NLP tasks to the right model family
- **Task 2:** Classified the sentiment of three sentences with DistilBERT
- **Task 3:** Summarized a short paragraph with FLAN-T5
- **Task 4:** Short reflection on why decoder-only models fit chatbots
- **Optional Challenge:** Showed how sampling and `set_seed` affect generated text
